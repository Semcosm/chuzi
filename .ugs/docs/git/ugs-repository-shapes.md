# UGS Repository Shape Capabilities

The optional `repository_shape` declaration records repository layout
capabilities without changing the Git-native Core.

```json
{
  "repository_shape": {
    "model": "single",
    "submodules": "none",
    "generated_files": "none",
    "large_files": "normal"
  }
}
```

`model` distinguishes a single project from a monorepo. `submodules` records
whether submodules are absent, permitted, or required. `generated_files`
describes whether generated outputs are absent, tracked, or regenerated by a
declared process. `large_files` records whether normal Git storage, a declared
large-file policy, or Git LFS is expected.

These are capability declarations, not universal workflow requirements. A
repository that does not declare this section remains valid v0.3, and tools
may provide shape-specific checks without changing the Core contract.
