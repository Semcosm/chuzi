# chuzi v0.0.1

`v0.0.1` is the first stable chuzi release. It packages the cross-platform
foundation, launcher management surface, and signed release verification chain
for Windows amd64, Linux amd64, Linux arm64, and macOS arm64.

Highlights:

- CHUZI launcher design language with Light and Dark themes.
- Solid, Frosted Glass, Mica, and Liquid Glass material treatments with local
  appearance persistence.
- Rust/Wry launcher UI for first-run setup, component and plugin management,
  update checks, settings, progress, and cancellation.
- Component archives, release manifests, release indexes, SHA-256 sidecars,
  and signed UGS attestations for stable release artifacts.
- Native desktop WebView helper builds and Linux X11/Wayland smoke coverage in
  the release matrix.

The release keeps the current project boundaries explicit. Production-grade
real-account browser automation, a production Matrix network client, and full
deployment/operations orchestration remain planned work. The default service
backend remains the Node.js deferred worker; Rust and headless browser backends
are explicit runtime selections.

Installation and platform prerequisites are documented in
[`RELEASE.md`](../RELEASE.md) and [`docs/operations.md`](../docs/operations.md).
