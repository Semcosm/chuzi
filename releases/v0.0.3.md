# chuzi v0.0.3

`v0.0.3` fixes the Windows launcher UI navigation policy that still produced
an empty WebView2 window in `v0.0.2`.

Highlights:

- Allow the exact lower-case `data:text/html;charset=utf-8;base64,` URI that
  Wry/WebView2 emits when loading the embedded launcher page.
- Keep navigation matching case-sensitive; uppercase schemes or parameters,
  external URLs, file URLs, and non-HTML data URLs remain denied.
- Preserve the existing launcher protocol, diagnostics, component management
  surface, and cross-platform package layout.

Installation and platform prerequisites are documented in
[`RELEASE.md`](../RELEASE.md) and [`docs/operations.md`](../docs/operations.md).
