# chuzi v0.0.4

`v0.0.4` establishes the CHUZI Design Language and migrates the Rust/Wry
launcher to its reusable Theme x Material contract.

Highlights:

- Add the complete CHUZI Design Language specification for Web UI, desktop UI,
  and a future shared component system.
- Define independent Light and Dark themes with Solid, Frosted Glass, Mica,
  and Liquid Glass materials across all eight Theme x Material combinations.
- Restrict authored UI colors to black, white, and alpha-derived grayscale;
  allow natural environment colors only through explicit page or host backdrop
  composition.
- Add capability-aware material resolution, stable Solid/Mica fallbacks,
  material-specific iOS/macOS interaction feedback, and reduced-effects paths.
- Document bounded refraction and physical edge dispersion for Liquid Glass;
  no synthetic rainbow or neon effect is used when a compositor cannot provide
  a real environment source.

The launcher keeps the existing `chuzi.launcher-ui/v1` IPC, component/plugin
management, update, settings, progress, and cancellation contracts unchanged.
Appearance preferences remain local to the UI.

Installation and platform prerequisites are documented in
[`RELEASE.md`](../RELEASE.md) and [`docs/operations.md`](../docs/operations.md).
